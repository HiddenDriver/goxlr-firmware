# GoXLR Firmware and Drivers
This archive contains the last (as of 04.08.2025) published versions of the GoXLR firmware and drivers.

Since TC Helicons layoffs no updates have been pushed anymore and the download servers for the beta firmware have been taken offline.  
The firmware update files in this archive have been archived on the GoXLR-on-Linux project Discord.

## Important
It is not possible for you to verify if these files have been tampered with and as such you (the user) have to trust these firmware files blindly.
If you are not comfortable doing this DO NOT USE THEM!

## Checksums
I have provided for each file the checksums so you can verify them after download.
Each file has a '.sha256' file containing its sha256 checksum.

## Beta Firmware
The included beta firmware is the last published firmware that enables the second Broadcast Stream Mix.
I also included the matching drivers for both stable and beta releases.
